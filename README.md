## Overview
This project is a clean, high-performance portfolio landing page tailored for software developers in Turkey. It is designed to showcase professional experience, technical skills, and project highlights in a localized, user-friendly interface. Whether you are a freelancer or a job seeker, this template provides a solid foundation for your online presence.
